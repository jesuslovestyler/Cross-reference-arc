# Cross-Reference Arc

An interactive picture of the Bible's cross-references — how verses answer and echo one another across the whole canon — the web of connection woven through the one Book.

**Live:** https://jesuslovestyler.github.io/Cross-reference-arc/
**Home:** https://jesuslovestyler.com/
